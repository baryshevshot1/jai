# Документация jai

## Рабочие документы (актуальные)

- **[Инструкция_тестирования.md](./Инструкция_тестирования.md)** — от чистой машины до
  проверенного приложения: установка по системам (Windows / Linux / macOS **и с флешки,
  без интернета**), первый запуск, чек-лист проверок с ожидаемым поведением.
- **[../CHANGELOG.md](../CHANGELOG.md)** — журнал изменений: **актуальное состояние по
  фичам**. Если сомневаешься, что уже работает, а что нет, — сюда.
- **[../README.md](../README.md)** — установка для пользователя, возможности, сборка
  флешки, разработка, структура проекта.
- **[../CLAUDE.md](../CLAUDE.md)** — контекст и жёсткие правила проекта (единственный
  движок, офлайн-первичность, кроссплатформенность, граница MVP/Стадии 2).

## Проектные документы (фаза проектирования — исторические)

- **MVP_руководство_процесс_Linux_Windows.html** — пошаговое руководство по разработке
  (11 фаз, 42 шага).
- **Инженерный_отчёт_финальный.html** — обоснование ключевых решений и набор моделей.
- **jai_дизайн_макет.html** — исходный HTML-прототип интерфейса.
- **Фаза_B_отчёт_по_заданию.md** — инженерная оценка задания «Документы, Фаза B (RAG)»
  против реального кода.

> ⚠️ Это **снимки замысла**, а не описание текущего продукта. С момента их написания
> интерфейс и логика ушли далеко вперёд: модель теперь подбирается автоматически
> (селектора в шапке нет), появились проекты, мастер установки и поставка с флешки,
> зрение и OCR, щадящий режим, онлайн-режим. Вкладок «Диалоги | Документы» в боковой
> панели больше нет — общая база документов живёт в настройках, база проекта — на экране
> проекта.
>
> **Единственный источник правды о том, что реализовано, — [`../CHANGELOG.md`](../CHANGELOG.md)
> и сам код.** Макеты и руководство используй как обоснование решений, а не как эталон.
