## Проверка премис C1-1 / C1-2 по текущему main (2026-08-04, до A1)

- **C1-2 («error decoding response body») — премиса устарела: баг исправлен и закреплён тестами.** Клиент больших загрузок (tools.rs:102-129) не имеет общего таймаута — только connect_timeout + read_timeout; voice.rs:278 использует именно его; регрессионный тест `no_total_timeout_on_the_download_path` берёт настоящую заготовку клиента (download.rs:649,687) и прошёл в прогоне E2; journal.rs:226-271 разворачивает цепочку source() у reqwest (тест закрепляет, что «error decoding response body» виден в причинах). Единственный `.timeout()` остался у клиента онлайн-слоя (tools.rs:159) — там он уместен. Для C1 остаётся: оценить полноту схемы логирования (байтовое смещение, Content-Length vs получено) против требований задания.
- **C1-1 (карточка голоса отсутствует в релизе) — премиса с высокой вероятностью устарела: механизм закрыт в волне PR #36–39.** Карточка строится кодом (settings.ts:831-856) с якорем на карточку «Документы»; в startup.test.ts:112-140 три регрессионных теста: карточка появляется (на реальной разметке index.html?raw), строится даже при отказе бэкенда на все команды, init голоса не роняет старт — все прошли (E2). Команды голоса регистрируются всегда (cfg-gated команд нет); release.sh:88 собирает с default features (voice включён); release.yml использует tauri-action без отключения фич. Остаточное: подтвердить на настоящем бандле (E3 → план верификации); замечена молчаливая ветка `if (!after) return;` (settings.ts:832-833) — обсудить в C1.
