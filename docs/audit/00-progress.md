## Ключевые факты A7 (для следующих сессий)

- **Движок присылает фактическую скорость и цену загрузки в каждом ответе, код их выбрасывает** (chat.rs:312-329 читает только done_reason и prompt_eval_count; grep по load_duration/eval_duration пуст). Автонастройка построена на предсказании при доступном бесплатном измерении — F-ENGINE-007.
