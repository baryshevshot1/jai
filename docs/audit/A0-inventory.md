## 5. Cargo-фичи и матрица сборки (E0 + E2 частично)

```toml
default = ["voice"]
voice   = ["dep:whisper-rs", "dep:cpal", "dep:rubato"]
devtools = ["tauri/devtools"]
```

- `--no-default-features`: собирается без cmake/C++ (whisper выключен); 6 голосовых команд остаются зарегистрированными и отвечают заглушкой `voice.rs:366-380` («Голосовой ввод не собран…») — cfg-gated tauri-команд нет вовсе, контракт IPC стабилен между конфигурациями.
- `--all-features` = voice + devtools; devtools лишь включает `tauri/devtools`.
- Фактическая компиляция (E2): обе конфигурации — default (voice) и `--no-default-features` — собираются чисто; clippy по всему workspace — 0 замечаний; тесты 80/80 (3 ignored требуют живой Ollama/сети и помечены явно). Заявление ADR-1 «сборка без voice обязана работать» подтверждено компиляцией в этой среде.

**Хорошее — одной строкой, чтобы не сломали при переделках:** гейт держит то, что проверяет, — clippy и tsc чистые, 160 юнит-тестов зелёные, Cargo.lock согласован, `.gitattributes` грамотно фиксирует LF/CRLF (критично для `.bat` на флешке), rust-toolchain закреплён точной версией. Чистота инструментов — свойство гейта, а не вывод о здоровье продукта: чего инструменты не видят (семантика ошибок, жизненный цикл процессов, состав бандла, поведение при отказах) — предмет этапов A2–A7.
