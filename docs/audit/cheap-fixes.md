## Связки: одна правка закрывает несколько находок

1. **«Отказ ≠ пустота» (~2–3 дня).** `F-BACKEND-001`, `F-BACKEND-006`, `F-BACKEND-008` (settings.json), `F-SECURITY-001` (журнал 152-ФЗ), `F-BACKEND-009` (список диалогов), `F-FRONTEND-002`/`F-FRONTEND-010` (фронтовая половина), **`F-RAG-003` и `F-RAG-009`** (та же болезнь в RAG: отсутствие результата не отличается от отказа, а индикатор источников не работает как признак). Один приём: различить `NotFound` и прочие отказы, вернуть `Err`, показать состояние «не удалось». **Закрывает 4 из 8 P0 плюс два P1.**
2. **«Наблюдаемость» (~1 день).** `F-BACKEND-004` (цепочка причин), `F-BACKEND-011` (аудиопоток мимо журнала), `F-BACKEND-014`/`F-BACKEND-018` (engine.rs нем), `F-FRONTEND-009` (11 точек set_setting), **`F-RAG-004`** (весь RAG-путь без единой записи). Один помощник записи + правки мест вызова. После этого разбор жалобы «отвечает не по моим документам» становится возможным вообще.
3. **«Async-атрибуты» (полдня).** `F-BACKEND-016`: пометить `#[tauri::command(async)]` команды истории, проектов, настроек, поиска носителей. Правка атрибута, поведение не меняется, замирание окна после каждого ответа уходит.
4. **«Стриминг» (~1 день).** `F-FRONTEND-014`: во время потока показывать обычный текст, полный Markdown — один раз на финале. Убирает 388 полных перерисовок из 388 на целевой машине.
