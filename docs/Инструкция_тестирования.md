# Инструкция по тестированию Jarvis AI — от загрузки до работы

Версия для тестирования: **v0.4.0** · страница выпуска:
<https://github.com/baryshevshot1/jai/releases/tag/app-v0.4.0>

> **Ссылки на скачивание заработают только после публикации выпуска `app-v0.4.0`.**
> На 3 августа 2026 он не собран: прогоны GitHub Actions падают за секунды с
> «account is locked due to a billing issue», а установщики под Windows и Linux
> взять больше неоткуда — Tauri не кросс-компилирует. Подробности и обходные пути —
> в [`RELEASE.md`](./RELEASE.md), раздел 2. До публикации тестируйте на 0.3.0,
> помня, что голосового ввода там нет.

Документ ведёт от чистой машины до проверенного приложения. Раздел 1 — установка
по системам (**включая установку с флешки, без интернета**), раздел 2 — первый
запуск (общий), раздел 3 — чек-лист проверок с ожидаемым поведением, раздел 4 —
что записывать, раздел 5 — известные особенности.

## 0. Что понадобится

| | Минимум | Комфортно |
|---|---|---|
| Система | Windows 10/11 x64 · Ubuntu 22.04+ · macOS (Apple Silicon) | — |
| Память | 8 ГБ ОЗУ | 16 ГБ ОЗУ или NVIDIA от 6 ГБ VRAM |
| Диск | ~15 ГБ свободно | 20+ ГБ (модели по 1–6 ГБ) |
| Интернет | только на время скачивания моделей | — |

Движок **Ollama устанавливается отдельно** (один раз, см. шаги ниже) — приложение
находит его само, запускает и гасит, но не устанавливает.

## 1. Установка

### 1.1 Windows 10/11

1. Скачать установщик:
   <https://github.com/baryshevshot1/jai/releases/download/app-v0.4.0/Jarvis.AI_0.4.0_x64-setup.exe> (203 МБ —
   внутри офлайн-установщик WebView2, докачивать ничего не нужно).
2. Запустить. Появится синее окно **«Система Windows защитила ваш компьютер»** —
   это нормально (сборка пока без платной подписи кода): **«Подробнее» →
   «Выполнить в любом случае»**. Антивирус может спросить то же — разрешить.
3. Установить Ollama: <https://ollama.com/download/windows> → `OllamaSetup.exe`
   → «далее-далее». Ollama появится в трее.
4. **Совет для машин с 6–8 ГБ видеопамяти**: выйти из Ollama в трее (правый клик
   по иконке → Quit). Тогда Jarvis AI поднимет движок сам, с экономными
   настройками памяти (одна модель в памяти, сжатый KV-кэш). Если Ollama
   оставить — приложение подключится к ней (тоже штатный режим, см. п. 3.7).

### 1.2 Linux (целевой стенд: Ubuntu + NVIDIA)

1. Скачать пакет:
   - Ubuntu/Debian: [`Jarvis.AI_0.4.0_amd64.deb`](https://github.com/baryshevshot1/jai/releases/download/app-v0.4.0/Jarvis.AI_0.4.0_amd64.deb)
     → `sudo apt install ./Jarvis.AI_0.4.0_amd64.deb` (зависимости подтянутся сами);
   - Fedora/RHEL: [`Jarvis.AI-0.4.0-1.x86_64.rpm`](https://github.com/baryshevshot1/jai/releases/download/app-v0.4.0/Jarvis.AI-0.4.0-1.x86_64.rpm);
   - любой дистрибутив: [`Jarvis.AI_0.4.0_amd64.AppImage`](https://github.com/baryshevshot1/jai/releases/download/app-v0.4.0/Jarvis.AI_0.4.0_amd64.AppImage)
     → `chmod +x` и запустить (если не стартует — установить `libfuse2`).
2. Установить Ollama: `curl -fsSL https://ollama.com/install.sh | sh`.
   Скрипт создаёт systemd-сервис `ollama` — он стартует сразу и при загрузке.
3. Проверить драйвер NVIDIA: команда `nvidia-smi` должна показать карту.
   Именно через неё приложение читает общую и **свободную** видеопамять.
4. **Два режима движка — интересно проверить оба** (см. п. 3.7):
   - сервис работает → приложение подключается к «внешнему» движку;
   - `sudo systemctl stop ollama` → приложение поднимает свой процесс
     с экономными настройками.

### 1.3 macOS (Apple Silicon)

1. Скачать [`Jarvis.AI_0.4.0_aarch64.dmg`](https://github.com/baryshevshot1/jai/releases/download/app-v0.4.0/Jarvis.AI_0.4.0_aarch64.dmg),
   перетащить в «Программы».
2. Первый запуск: **правый клик по приложению → «Открыть» → «Открыть»**
   (Gatekeeper предупредит о неподписанном приложении — нотаризация в Стадии 2).
3. Ollama: <https://ollama.com/download/mac> либо `brew install ollama`.

### 1.4 С флешки — установка вообще без интернета

Это **основной сценарий у клиента**, и его стоит проверить отдельно: машина без
сети, всё ставится с носителя.

1. Собрать флешку (на машине разработчика, флешка в **exFAT**, от 16 ГБ):
   ```bash
   tools/make-usb.sh --out /Volumes/JAI --installers --models "qwen3.5:9b qwen3.5:4b bge-m3" --version app-v0.4.0
   ```
2. На чистой машине **отключить интернет** и запустить с флешки:
   - Windows: `Windows\Установить.bat` (поставит Ollama и приложение молча);
   - Linux: `bash Linux/install.sh` (спросит пароль sudo);
   - macOS: перетащить `.dmg` в «Программы», Ollama поставить отдельно.
3. Запустить **Jarvis AI** → мастер установки должен **сам найти папку `models`
   на флешке** и предложить импорт.
4. После импорта **извлечь флешку** → приложение продолжает работать: чат
   отвечает, поиск по документам работает. Интернет не нужен ни разу.

## 2. Первый запуск (все системы одинаково)

1. Запустить **Jarvis AI**. В шапке справа — статус движка: зелёный огонёк,
   **«Готов к работе»** и серым рядом **«Ollama 0.30.x»**. Если «Движок не
   отвечает» или «Движок не установлен» — см. «Если что-то не так» в конце.
2. **Мастер установки** откроется сам, если обязательных моделей ещё нет: он
   покажет, что за компьютер перед ним, отметит модели, которые тот потянет
   (непосильные — заблокированы), и предложит источник: флешка или интернет.
   Это штатный путь. Мастер всегда можно открыть снова:
   **Настройки → Модели → «Мастер установки…»**.
3. Если ставить модели вручную: шестерёнка → раздел **«Модели»** → «Установить»:
   - `qwen3.5:9b` — основная модель чата, ~6,6 ГБ (**обязательная**);
   - `bge-m3` — поиск по документам, ~1,2 ГБ (**обязательная**);
   - по желанию: `qwen3-vl:4b` (картинки и OCR, ~3,5 ГБ), `qwen3-coder` (код),
     `qwen3.5:4b` (лёгкая, для слабых машин).

   У установки виден прогресс в процентах и гигабайтах; есть честная «Отмена».
   *Без интернета* — кнопка **«Импорт с флешки/диска…»** в том же разделе.
4. Шестерёнка → **«Проверка системы»**: шесть пунктов (движок, модели, база
   документов, диск, железо, хранилище) — все «ОК» либо с понятным объяснением.

После этого приложение полностью готово: чат работает офлайн, интернет больше
не нужен.

> **Модель выбирать не нужно.** В шапке селектора моделей нет: приложение само
> берёт текстовую модель под ваше железо, а на вопрос с картинкой — модель
> зрения. Какая модель активна, видно в блоке железа слева внизу.

## 3. Чек-лист проверок

Каждый пункт: действие → **ожидаемое поведение**. Отмечай, что прошло/нет.

### 3.1 Чат и «Стоп»

- [ ] Вопрос в чате → ответ печатается постепенно (стриминг), поле ввода
      заблокировано до конца ответа.
- [ ] «Стоп» посреди длинного ответа → генерация прерывается, **частичный ответ
      сохраняется** в истории (не исчезает).
- [ ] **«Стоп» сразу после первого вопроса «холодной» модели** (первый запрос
      после запуска, пока крутится «Думаю…» и токенов ещё нет) → интерфейс
      разблокируется сразу, без зависания. *Раньше «Стоп» не действовал, пока
      модель грузилась в память.*
- [ ] Ответ с форматированием: попроси «таблицу умножения в маркдаун-таблице,
      формулу дискриминанта и пример кода на Python» → таблица, формула
      (красиво свёрстана) и код с подсветкой; кнопка **«Копировать»** у кода
      работает. *Проверяет ленивый чанк рендера.*
- [ ] Тумблер «Размышления» (для qwen3.5): включён → перед ответом видно
      «Рассуждение», по клику раскрывается. Учти: с размышлениями даже простые
      вопросы думаются 20–30 секунд — это особенность модели, не зависание.

### 3.2 История диалогов

- [ ] Закрыть приложение и открыть снова → последний диалог восстановился.
- [ ] Поиск по списку диалогов; удаление одного (с подтверждением);
      «Очистить всё».
- [ ] Новый чат → приветственный экран с чипами-подсказками.

### 3.3 Проекты

- [ ] Создать проект, вписать **инструкции** (например: «Отвечай односложно») →
      новый чат проекта следует инструкциям, а быстрый чат вне проекта — нет.
- [ ] Добавить документ в «Знания проекта» → чат проекта отвечает по нему;
      **быстрый чат вне проекта этот документ не видит**.
- [ ] У открытого чата проекта в шапке виден чип с именем проекта; клик по
      чипу открывает экран проекта.
- [ ] Удалить проект → его чаты и документы исчезли (каскад), открытый чат
      сменился новым быстрым.

### 3.4 Документы и поиск (RAG)

- [ ] **Настройки → «Документы (быстрые чаты)»** → «Добавить документ» → PDF,
      DOCX, TXT или MD → прогресс индексации → документ в списке.
      *Отдельной вкладки «Документы» в боковой панели больше нет — общая база
      живёт в настройках, база проекта — на экране проекта.*
- [ ] Вопрос по содержимому документа → ответ опирается на него, под ответом
      строка **«Источники: …»** (показывается один раз на документ за диалог).
- [ ] Вопрос НЕ по документам («сколько будет 2+2») → обычный ответ, без
      притянутых источников.
- [ ] Удаление документа из базы.
- [ ] *Продвинутый (по желанию): устойчивость к повреждению базы.* Закрыть
      приложение, испортить файл базы:
      - Windows (PowerShell): `Set-Content "$env:APPDATA\ru.baryshevshot.jai\documents.db" "мусор"`
      - Linux: `echo мусор > ~/.local/share/ru.baryshevshot.jai/documents.db`
      - macOS: `echo мусор > ~/Library/Application\ Support/ru.baryshevshot.jai/documents.db`
      Открыть приложение → **не падает**, база пуста (пересоздана), рядом лежит
      копия `documents.db.corrupt.bak`, «Проверка системы» показывает
      предупреждение о пересоздании.

### 3.5 Установка моделей — честность менеджера

- [ ] Начать установку модели → **«Отмена» посреди закачки** → сообщение
      «установка отменена», модель НЕ помечена установленной/актуальной.
      *Раньше отмена рапортовала «установлено».*
- [ ] Нажать «Установить» повторно → докачка **продолжается с места**, не с нуля.
- [ ] Пока идёт установка — все остальные кнопки установки (в «Документах»,
      в каталоге, «с диска») заблокированы.
- [ ] Выключить интернет посреди закачки → прогресс замирает, «Отмена»
      срабатывает сразу; если ничего не нажимать — через ~2 минуты честная
      ошибка «Сеть не отвечает… докачка продолжится с места».
- [ ] «Проверить обновления» в разделе «Модели» → у установленных бейджи
      «актуальна», итог в кнопке («Актуально» / «Есть обновления»).

### 3.6 Картинки, OCR и авто-выбор модели

- [ ] Прикрепить фото/скриншот с текстом → «Извлечь текст» → распознанный
      текст в ответе.
- [ ] **Модели зрения нет** → при прикреплении картинки приложение предлагает
      установить `qwen3-vl:4b` (у плашки установки есть «Отмена»).
- [ ] **Авто-модель.** Модель зрения установлена: задать обычный текстовый
      вопрос → внизу слева в блоке железа активна текстовая модель
      (`qwen3.5:…`). Прикрепить картинку и спросить про неё → ход уходит на
      модель зрения (уведомление в ленте). Следующий обычный вопрос **сам**
      возвращается к текстовой — переключать ничего не надо.
- [ ] **Ручной выбор (для поддержки).** Настройки → Модели → «Модель для
      ответов» → выбрать конкретную → она и отвечает; вернуть «Автоматически» →
      снова подбирается сама. Выбор переживает перезапуск.
- [ ] *Продвинутый:* удалить выбранную вручную модель из Ollama и перезапустить
      приложение → оно честно возвращается к «Автоматически», а не падает.

### 3.7 Железо и память — главное на стенде с NVIDIA

- [ ] Блок «Железо» внизу панели: `GPU N ГБ (свободно X) · RAM … · CPU …` —
      **свободная видеопамять видна и правдоподобна** (сравни с `nvidia-smi`).
      *Новое в v0.3.0 — раньше показывался только паспортный объём.*
- [ ] Занять видеопамять (игра, вторая нейросеть, большой Chrome) → первый
      запрос к модели → плашка **«Модель не помещается целиком в свободную
      видеопамять — ответ будет медленнее»** (показывается один раз на модель
      за сессию).
- [ ] На машине, где памяти впритык: плашка «контекст снижен до …» или честный
      отказ «Не запускаю…: не хватает …» — вместо зависания системы.
- [ ] **Два режима движка (Linux)**: с работающим сервисом `ollama` оценка
      памяти консервативнее (внешний движок держит KV-кэш в f16) — модель может
      раньше получать сниженный контекст; после `sudo systemctl stop ollama` и
      перезапуска приложения движок поднимается «своим» (экономный режим) —
      запас памяти больше. Оба режима должны работать.
- [ ] Выход из приложения: если движок поднимало ОНО (не системный сервис) —
      процессов `ollama` не остаётся (`pgrep -a ollama` / диспетчер задач).
      Системный/внешний экземпляр приложение не трогает.

### 3.8 Шапка, настройки и онлайн-режим

- [ ] **Чип движка в шапке**: зелёный огонёк, «Готов к работе», серым рядом
      «Ollama 0.30.x». Остановить движок (`sudo systemctl stop ollama` /
      выйти из Ollama в трее) → кнопка обновления в шапке → огонёк гаснет,
      «Движок не отвечает», **подпись с версией пропадает** (висящая версия при
      погасшем огоньке была бы враньём).
- [ ] **Бренд = «на главную»**: открыть Настройки → нажать «Jarvis AI» слева
      вверху → возврат к чату. То же с экрана проекта и из мастера установки.
- [ ] **Щадящий режим** (Настройки → «Движок и производительность»): на слабой
      машине включён сам и помечен «(по оценке железа)»; переключается вручную
      и переживает перезапуск.
- [ ] **Кнопка «Проверить»** в «Проверке системы»: нажать → строки обновляются,
      под списком появляется итог **«Проверено в ЧЧ:ММ · всё в порядке (6
      проверок)»**. Нажать ещё раз → **время в итоге меняется** (видно, что
      кнопка отработала, даже если результат тот же).
- [ ] Тема (светлая/тёмная) переключается и **переживает перезапуск**; ширина
      боковой панели тянется и тоже сохраняется.
- [ ] Онлайн-режим **по умолчанию выключен**. Отдельного индикатора в шапке нет:
      индикатор — сам тумблер «Онлайн» в строке ввода (во включённом состоянии
      подсвечен, на нём горит пульсирующая точка).
- [ ] *По желанию, если есть ключ Tavily*: включить онлайн в настройках, вписать
      ключ → вопрос «какой сейчас курс доллара?» → статус «Ищу в интернете…»,
      ответ со строкой «Источники из интернета»; в настройках журнал исходящих
      обращений показывает, что и куда уходило; при выключенном тумблере — чат
      строго офлайн.
- [ ] *Известное ограничение:* у бесплатного ключа Tavily 1000 кредитов в месяц,
      а один поиск стоит 2 → примерно **500 поисков в месяц**. Когда кончатся,
      веб-поиск перестанет работать до следующего месяца. Запасной провайдер и
      автопереключение — в работе (Яндекс + SearXNG).

### 3.9 Обновление приложения (контур доставки)

- [ ] *Если стоит v0.2.0*: «Настройки → Обновления приложения → Проверить
      обновления» → «Доступна версия 0.4.0» → «Установить» → загрузка,
      установка, перезапуск новой версии. *Это главный тест канала доставки
      будущих версий.*
- [ ] «Установить обновление с диска…» — выбирается файл установщика (проверка
      без интернета).

### 3.10 Голосовой ввод — новое в 0.4.0, живьём не проверялся ни разу

Диктовка вместо набора: зажали кнопку микрофона, сказали — текст появился в поле.
Речь распознаётся **на этом компьютере**, запись никуда не уходит. Нужна отдельная
модель распознавания (~465 МБ), её ставят один раз.

Раздел важнее остальных: **всё, что ниже, автотестами не проверено.** Проверено
другое — что загрузка не обрывается и что файл не портится; как это выглядит и
ощущается в живом окне, впервые увидите вы.

- [ ] «Настройки» → карточка **«Голосовой ввод»** на месте, под «Документами».
- [ ] Модель не установлена → **кнопки микрофона в строке ввода НЕТ**. Так и
      задумано: нерабочая кнопка хуже отсутствующей.
- [ ] **«С флешки/диска…»** — основной путь. Приложение само находит носитель и
      предлагает его; с битым файлом отказывает понятной фразой, а не «error».
- [ ] **«Установить»** (нужен интернет) — идёт загрузка; в подписи видны проценты,
      мегабайты, **скорость и сколько осталось**.
- [ ] **Выдерните Wi-Fi на 10 секунд посреди загрузки.** Загрузка обязана
      продолжиться сама, прогресс — не откатиться на ноль. *Это главный тест
      раздела: раньше загрузка обрывалась всегда и начиналась заново.*
- [ ] **«Отмена»** посреди загрузки → карточка пишет «скачано N из M» и предлагает
      **«Продолжить»**; после нажатия загрузка идёт дальше, а не с начала.
- [ ] **«Начать заново»** выбрасывает недокачанное и начинает с нуля.
- [ ] После установки **кнопка микрофона появляется без перезапуска приложения**.
- [ ] Зажать микрофон, сказать фразу, отпустить: «Говорите…» → «Распознаю…» →
      текст **дописывается** к уже набранному, не затирая его.
- [ ] Отпустить кнопку, уведя курсор далеко в сторону — запись не залипает.
- [ ] Alt+Tab во время записи — микрофон закрывается, сказанное распознаётся.
- [ ] **Escape** во время записи — микрофон закрывается, в поле **ничего** не
      дописывается (передумал — значит передумал).
- [ ] Очень короткое нажатие («тык») — понятная подсказка, а не ошибка.
- [ ] **Качество русского.** Продиктуйте 3–4 рабочие фразы со своей лексикой
      (названия, суммы, юридические обороты) и оцените честно. Стоит модель
      `small` — компромисс между точностью и размером флешки. Если разбирает
      плохо, скажите: есть `medium`, точнее, но втрое тяжелее для носителя.

## 5. Известные особенности (не баги)

- **Предупреждения при установке** (SmartScreen на Windows, Gatekeeper на
  macOS) — сборка без платной подписи кода; подпись запланирована на Стадию 2.
- **Первый ответ после запуска/простоя медленный** — модель грузится в память
  (десятки секунд на HDD/слабом железе). Дальше быстро.
- **«Размышления» = +20–30 секунд** даже на простые вопросы — особенность
  reasoning-режима qwen3.5, выключается тумблером.
- **6 ГБ VRAM + модель 9B — впритык**: снижение контекста и предупреждение про
  видеопамять на таком железе — штатная работа защиты, не ошибка.
- Приложение **не устанавливает Ollama** — это разовый шаг при развёртывании.

## Если что-то не так

- «Движок не установлен» → шестерёнка → **«Движок и производительность»** →
  «Указать…» → путь к исполняемому файлу Ollama (Windows:
  `C:\Users\<имя>\AppData\Local\Programs\Ollama\ollama.exe`;
  Linux: `/usr/local/bin/ollama`; macOS: `/opt/homebrew/bin/ollama`).
- Модели не видны после локальной поставки → проверить, что указанный каталог
  содержит подпапки `manifests` и `blobs`.
- Мастер установки не находит флешку → в разделе «Модели» нажать
  «Импорт с флешки/диска…» и указать папку `models` на носителе вручную.
- Всё прочее — скриншот «Проверки системы» и описание шагов.
